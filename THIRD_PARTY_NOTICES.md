# Third-party resources

This research implementation was developed using the public UrbanSSF project
as its experimental framework:

- UrbanSSF: <https://github.com/KotlinWang/UrbanSSF>
- Associated paper: *Accurate Segmentation of Urban Spatial Structure: A
  Framework for Large-Scale Remote Sensing Images Using Feature State Sequences*.

The proposed CDFM, DP-MPC, DGR-CSMamba, detail-decoder, controlled-ablation,
strict-split, and paper-result files were added for the submitted study.

The current working copy of UrbanSSF did not contain a root-level license file.
Before adding a permissive license to this repository, the authors should obtain
or verify the necessary permission for any retained framework-derived files.

The ISPRS Vaihingen and Potsdam datasets are not included. They must be obtained
from the official benchmark site and used under the benchmark's terms.

Individual Python dependencies remain subject to their own licenses.
